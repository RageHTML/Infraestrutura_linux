Roteiro de apresentaco 

DMZ: zona delimitadora e uma rede responsavel por expor servicos para redes nao seguras ela e um adicional de seguranca a rede lan
Ngix: Utilizei o Ngix para ser o dmz, ngix e um servidor http flexivel e com alta performace


Configurei o ip estatico via netplan
sudo systemctl enable --now systemd-networkd
sudo mkdir -p /etc/netplan
sudo nano /etc/netplan/99-dmz.yaml

Módulo M1: 
Endereçamento e Roteamento: Configuração estática de interfaces via Netplan,
systemd-networkd ou NMT (netplan)
Verificar endereco das redes: ip a
Verificar a tabela de roteamento: ip route
Validar configuração do Netplan: sudo netplan status sudo netplan try

Serviço DHCP: Servidor DHCP (ISC DHCP) alocando IPs na
sub-rede LAN com reservas estáticas de IP para servidores.
verificar status: sudo systemctl status isc-dhcp-server
vericar logs: sudo journalctl -u isc-dhcp-server -f
Verificar o arquivo de concessões ativas: cat /var/lib/dhcp/dhcpd.leases

DNS Interno: Servidor DNS local (Bind9) realizando a resolução
direta e reversa para o domínio corporativo (ex: empresa.local)
verificar status: sudo systemctl status bind9
Validar a sintaxe dos arquivos de configuração e zona:sudo named-checkzone fastservice.local /etc/bind/db.fastservice.local

Módulo M2: 
Verificar 

Instalação do PostgreSQL 15+, ajustando o postgresql.conf para escutar nas interfaces corretas da DB Zone.
verificar sudo -u postgres psql -c "SHOW listen_addresses;"
sudo ss -tlnp | grep 5432


Controle de Acesso Fino: Edição do pg_hba.conf para restringir conexões
exclusivamente para a sub-rede da DMZ / Servidor Web via autenticação MD5
sudo -u postgres psql -c "SELECT line_number, type, database, user_name, address, auth_method FROM pg_hba_file_rules;"

Políticas de Privilégio Mínimo: Separação clara entre superusuários do banco e
usuários de aplicação sem privilégios administrativos.
sudo -u postgres psql -P pager=off -d recadastro -c "\du" -c "\dp usuario"

realização diária de pg_dump, compactação em .tar.gz e envio para o Servidor
de Arquivo
sudo crontab -u postgres -l; sudo tail -n 3 /var/backups/postgres/backup.log; sudo ls -lh /compartilhado/backups

Segurança de Borda (Firewall): Implementação via iptables
garantindo bloquear por padrão (DROP) todo o tráfego não explicitamente
permitido.

Verificar as políticas padrão: sudo iptables -L -v
. Verificar se as regras e exceções foram aplicadas: sudo iptables -L -n -v --line-numbers
